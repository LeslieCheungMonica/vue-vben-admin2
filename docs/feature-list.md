# 平台功能清单（三级）

> 基于路由结构（`apps/web-antd/src/router/routes/modules/*`）、菜单配置（`apps/web-antd/src/config/menu.ts`）与各页面 API 调用梳理。
>
> 层级说明：一级模块 = 菜单模块；二级功能 = 页面/子模块；三级功能点 = 页面内具体操作能力。

## 一、认证与用户中心

### 1.1 登录认证（`/auth/*`）

| 三级功能点 | 功能描述 |
|---|---|
| 账号密码登录 | 输入账号密码完成登录鉴权，获取令牌与权限码 |
| 验证码登录 | 手机/邮箱验证码方式登录 |
| 二维码登录 | 扫码方式登录 |
| 忘记密码 | 找回/重置密码流程 |
| 用户注册 | 新账号注册 |

### 1.2 用户中心（`/profile`）

| 三级功能点 | 功能描述 |
|---|---|
| 基础设置 | 个人基础信息维护 |
| 安全设置 | 账号安全相关配置 |
| 密码设置 | 修改登录密码 |
| 通知设置 | 站内通知偏好设置 |

## 五、敏感数据检测（核心业务模块）

### 5.1 总览（`/sensitive/home`）

| 三级功能点 | 功能描述 |
|---|---|
| 统计卡片 | 总日志数、检测发现数、高危接口数、风险接口数 |
| 风险等级分布 | 饼图展示风险等级分布 |
| 敏感类型分布 | 柱状图展示敏感类型分布 |
| 高危接口 Top5 | 列表展示高危接口（服务/路由/风险等级/敏感类型），可跳转查看更多 |

### 5.2 数据查询（`/sensitive/data`）

| 三级功能点 | 功能描述 |
|---|---|
| 日志列表查询 | 按时间范围/接口路径/操作员ID/检测状态多条件筛选分页查询 |
| 日志详情 | 查看请求头、请求体、响应状态、响应体及关联检测结果 |
| 单条日志检测 | 对未检测日志调用规则+LLM 检测（防误操作确认） |
| 新增并检测 | 手工录入接口路径/请求体/响应体，提交后即时完成检测并展示规则命中与 LLM 结果 |
| 检测结果查看 | 查看规则引擎命中类型、LLM 检测明细（敏感字段/脱敏值） |

### 5.3 检测结果（`/sensitive/detection`）

| 三级功能点 | 功能描述 |
|---|---|
| 结果列表查询 | 按风险等级（严重/高/中/低）、敏感类型、操作员、时间筛选 |
| 检测详情 | 展示敏感类型、风险等级、确认状态、敏感信息明细（类型/字段/脱敏值/来源） |
| LLM 批量复检 | 全量或按接口路径复检，展示进度、检出/安全/LLM成功/失败统计及逐条明细（规则命中/LLM 判定/敏感类型） |

### 5.4 评估报告（`/sensitive/report`）

| 三级功能点 | 功能描述 |
|---|---|
| 生成报告 | 一键生成敏感信息检测评估报告 |
| 报告展示 | 报告编号/时间/综合风险等级、分析日志数、风险等级分布进度条、敏感类型分布、高危接口列表、安全建议 |

### 5.5 模型配置（`/sensitive/model`）

| 三级功能点 | 功能描述 |
|---|---|
| 模型列表 | 展示检测模型（规则模型/LLM 模型、敏感类型、优先级、启用状态） |
| 编辑模型 | 修改名称/正则规则/优先级/描述，切换启用状态 |
| 启用/禁用 | 快捷开关模型 |
| 模型测试 | 输入测试文本执行检测，展示命中、置信度、匹配结果 |

### 5.6 知识增强（`/sensitive/knowledge`）

| 三级功能点 | 功能描述 |
|---|---|
| 知识库列表 | 按分类 Tab（法规规范/行业标准/案例分析/技术方案）分页浏览 |
| 知识搜索 | 关键字检索知识条目 |
| 新增知识 | 录入标题/分类/内容/标签/来源 |
| 知识详情 | 查看完整知识内容 |
| AI 知识增强 | 输入查询描述，自动检索并扩充知识库（展示新增条目数） |

### 5.7 AI 助手（`/sensitive/agent`）

| 三级功能点 | 功能描述 |
|---|---|
| 多轮对话 | SSE 流式对话，支持自动多轮分析与推理 |
| 过程步骤展示 | 思考/工具调用/观察结果分步实时展示 |
| 快速提问 | 快捷问题（数据情况/高危接口/敏感分布/安全建议） |
| 结构化风险数据 | 风险等级定义、敏感类型分布、风险接口明细表格 |
| AI 扫描渗透 | 对风险接口发起模拟渗透扫描（代码定位→漏洞侦查→渗透测试→生成报告） |

### 5.8 LLM 配置（后端能力）

| 三级功能点 | 功能描述 |
|---|---|
| 查看配置 | 获取 LLM Provider/模型/API 地址/参数配置 |
| 更新配置 | 修改 LLM 连接配置 |
| 连接测试 | 测试 LLM 连通性 |

## 说明

- **一级模块**：菜单模块；**二级功能**：页面/子模块；**三级功能点**：页面内具体操作能力。
- **敏感检测模块**：独立后端服务（FastAPI `:8001`），接口前缀 `/native-security/*`。
- **业务测绘 / API 探测 / COSMIC**：走 WAPE 服务（`:7654`）。
